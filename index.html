The problem

  • A separate hard-coded screen for every item category
  • Item and Spare-part flows duplicated grid by grid

The engineering

    06 / how I work

    Four rules I build by.

    1. 01

      Configure, don't hard-code.

      If a new item category needs a code change, the design is wrong. Metadata should drive the form.

    2. 02

      Never break what already works.

      Refactors in a large codebase keep every existing validation and backend behaviour.

    3. 03

      The data has to be right.

      T-SQL checks across hundreds of records come before the UI looks finished.

    4. 04

      Listen to the people using it.

      Bulk allocation, consistent buttons and responsive grids all came from user feedback.
